# Architecture Decision Records (ADRs)

Un **ADR** (Registro de Decisión de Arquitectura) es un documento que captura una decisión de diseño arquitectónico importante tomada en el proyecto, junto con su contexto, las opciones consideradas y sus consecuencias.

Seguimos el estándar **MADR** (Markdown Architectural Decision Records).
